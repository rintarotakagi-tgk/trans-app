# Excel シート結合ツール

複数のExcelファイルから指定したシートを抽出し、1つのファイルに結合するWebアプリケーションです。

## 機能

- 複数のExcelファイル（.xlsx / .xls）を一括アップロード
- ドラッグ&ドロップまたはファイル選択でアップロード
- 結合するシート名をカスタマイズ可能
- シートごとにデータを縦結合（ヘッダーは1行のみ）
- 元ファイル名を各行に自動追加
- 結合結果を個別にダウンロード
- ブラウザ内で完結（サーバー不要）

## 技術スタック

- React 18
- Vite
- SheetJS (xlsx)

## セットアップ

### 依存関係のインストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist` フォルダに出力されます。

### プレビュー

```bash
npm run preview
```

ビルドされたアプリをローカルでプレビューします。

## 使い方

1. Excelファイルをドラッグ&ドロップ、またはクリックしてファイルを選択
2. アップロードされたファイル一覧を確認
3. 必要に応じて結合するシート名を変更
4. 「結合する」ボタンをクリック
5. 結合結果のダウンロードボタンからファイルを取得

## デフォルトのシート名

- シート①: `アクセスへコピペ用 Sheet1（見積情報）`
- シート②: `アクセスへコピペ用　Sheet2(案件情報）`

## デプロイ

このアプリはVercelやNetlifyなどの静的ホスティングサービスに簡単にデプロイできます。

### Vercelへのデプロイ

```bash
npm install -g vercel
vercel
```
